Switch shortcuts

Record a combination on the USB keyboard or mouse attached to the bridge. Cycle, Next, and Previous each keep keyboard and mouse bindings. Slot is keyboard-only. Recording updates only the captured input type. Mouse buttons can include keyboard modifiers. Cycle and Next move forward; Previous moves backward. All skip disconnected computers and wrap around. With no other connected computer, selection stays unchanged. Slot records modifiers to use with 1/2/3 and can select disconnected or empty slots. Recorded shortcuts are consumed by the bridge.
