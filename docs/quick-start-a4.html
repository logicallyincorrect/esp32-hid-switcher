HID Switcher

One keyboard and mouse · three computers

What you need

  • Freenove ESP32-S3 board and the supplied case
  • USB keyboard and mouse, plus a powered hub if needed
  • USB cable connected to the board's UART/programming port
Do not erase flash during an update unless you intentionally want to remove pairings, names, shortcuts, and calibration.

Choose a setup path

Web UI: use the USB UART/programming port and a Chrome-compatible browser. This works before an input keyboard is paired.

On-board menu: connect a USB keyboard and mouse, open a blank text document, and hold BOOT for three seconds. The board types its menu into the document.

1 · First-time setup

  1. Open https://logicallyincorrect.github.io/esp32-hid-switcher/.
  2. Use Chrome or another browser with Web Serial support.
  3. Click Connect board, choose the USB serial port, and read the current settings.
  4. If needed, click Install firmware. Choose a version and approve disconnecting the board for flashing.

Web UI configuration

Work from top to bottom: connect the board, configure inputs, pair and name outputs, then configure switching. Sections appear as prerequisites become available. Changes save to the board immediately.

Pair each computer with HID SWITCHER BLE. Give each slot a name. Drag the slot handle to reorder it; the complete slot record moves together.

On-board configuration

Choose Computers to pair, rename, select, or forget outputs; Shortcuts to record bindings; Bluetooth name to rename the switcher; and Diagnostics for status. The BLE input build adds a BLE input menu.

USB devices appear automatically. For a BLE keyboard or keyboard/trackpad, choose Add BLE device, scan, select the device, complete pairing, then assign its input to a slot.

Only BLE HID devices with supported keyboard or relative-pointer reports can forward input. Proprietary 2.4 GHz devices are not BLE.

2 · Configure features

Web UI: in Switching, click the pencil beside a keyboard or mouse cell. Press the shortcut, release it, and the cell saves automatically. The × clears it.

On-board: choose Shortcuts, select an action and input type, press the desired keys or mouse button, release them, then confirm.

  • Cycle moves to the next connected computer.
  • Next / Previous move one connected slot.
  • Slot selects a numbered slot.

Seamless edge switching

Turn it on only after the output layout is ready. Drag the monitor tiles to match the physical desk. Click the pencil beside each resolution and speed to edit values inline; click the checkmark to save.

Web UI: turn it on, arrange monitor tiles, edit resolution and speed inline, then calibrate one or all connected computers. On-board: choose Seamless switching, enable it, and follow the corner prompts.

Disconnected outputs are skipped. When a slot reconnects, its saved position and dimensions return to the layout.

3 · Daily use

Only the selected computer receives keyboard and mouse input. Select a slot with its shortcut, the BOOT menu, or the web UI.

BLE input recovery

Open Input Devices. A saved device can be reconnected, disconnected, or forgotten. Disconnect before scanning for a replacement. Pairing prompts must be confirmed for the current attempt.

Board menu

Open a blank US-layout text document, turn Caps Lock off, then hold BOOT for three seconds. Press Esc to go back and BOOT to exit.

Keep the text document focused while using the menu. Esc goes back; BOOT exits. Both configuration paths edit the same saved settings.

Troubleshooting

No board in Connect board

Use the UART/programming port, try another data cable, close serial monitors, and reconnect. A CH340 UART adapter cannot act as the USB host.

Keyboard or mouse is dead

Check that the hub is powered, the board is connected to the correct USB port, and the selected slot is paired. Test the keyboard directly before replacing the hub.

BLE pairing problems

  • Keep the BLE device awake and advertising.
  • Forget old bonds on both sides before retrying.
  • For a numeric comparison prompt, confirm the same code on both devices.
  • If the scan is empty, use Scan all BLE devices; non-connectable advertisers still cannot pair.

The BLE input experiment uses one saved wireless input and is separate from the three computer output connections.

Seamless switching problems

Set the actual pixel dimensions in the monitor tiles. Recalibrate after changing display scaling, mouse DPI, or host pointer settings. Move steadily between corners.

If a display is offline, it is deliberately skipped. Reconnect it and refresh the page to restore it to the saved arrangement.

Dragging, held keys, and the setup menu temporarily block edge switching.

Keep this sheet

Firmware and web setup are versioned in the repository. Check the README before upgrading.

Safe update

  1. Connect the board in the web setup page.
  2. Choose Install firmware and approve the disconnect.
  3. Leave erase disabled.
  4. Reconnect and verify that pairings and names remain.

For logs and diagnostics, use the BOOT menu's Diagnostics screen. Full serial and troubleshooting instructions are at the repository URL on the other side.
